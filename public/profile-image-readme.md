# Profile Image

Add your professional profile photo here as `profile.jpg`.

## Recommended Specifications

- **File name**: profile.jpg
- **Format**: JPG or PNG
- **Dimensions**: 400x400 pixels (square)
- **File size**: < 500KB
- **Quality**: High resolution, professional headshot
- **Background**: Clean, professional, or transparent

## Alternative

If you prefer not to use a profile image, the Hero component currently displays a placeholder with your initials (NP). You can customize this in `src/components/Hero.jsx`.

To use an actual image, uncomment and modify the image tag in the Hero component.
