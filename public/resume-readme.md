# Resume PDF Instructions

## To enable the "Download Resume" button:

1. Create a PDF version of your resume
2. Save it as `resume.pdf` 
3. Place it in this `/public` folder
4. The download button will automatically work

The button is configured to download the file as `Niladri_Podder_Resume.pdf` when clicked.

If you want to change the downloaded filename, edit the `download` attribute in `/src/components/Contact.jsx`
